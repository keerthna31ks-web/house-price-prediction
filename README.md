# 🏠 House Price Prediction

## 📌 Project Overview

This project focuses on predicting house sale prices using machine learning.

The project uses the **Kaggle House Prices: Advanced Regression Techniques** dataset and demonstrates a complete machine learning workflow, from data exploration and preprocessing to model training, evaluation, and generating predictions for Kaggle submission.

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 🔄 Machine Learning Workflow

1. Loaded and explored the dataset
2. Performed data cleaning and analysis
3. Handled missing values
4. Analyzed numerical and categorical features
5. Applied feature preprocessing
6. Encoded categorical variables
7. Built preprocessing pipelines
8. Trained regression models
9. Evaluated model performance
10. Generated predictions for the Kaggle test dataset
11. Prepared and submitted predictions to Kaggle

## 📊 Data Preprocessing

The following preprocessing techniques were used:

- Missing value handling
- Numerical feature preprocessing
- Categorical feature encoding
- Feature transformation
- Scikit-learn Pipeline

## 🤖 Model Development

Regression-based machine learning techniques were used to predict house sale prices.

Model performance was evaluated using:

- MAE (Mean Absolute Error)
- RMSE (Root Mean Squared Error)
- R² Score

## 🏆 Kaggle Result

The final predictions were submitted to the Kaggle House Prices competition.

**Kaggle Score:** `0.13278`
